settings, the composition root, and the thin Python entry point. The Phase 0
commit also includes source contracts, the fixed roster, and the memory adapter.

Person B added the React/TypeScript shell, Vite development proxy, component
tests, build configuration, and updated setup instructions. Frontend files stay
directly under `src/frontend`; its Python package marker is retained.

Run instructions are in the root README. Frontend dependency installation,
component tests, and the production build have not been run in this pass,
following the user's request to prioritize code and stop additional checks.
An npm lockfile will be generated by the first dependency installation.

  deferred. Earlier durable-storage requirements are superseded for this prototype.

  supporting progress transport when the workflow is connected.
- Historical-source reliability and live model compatibility remain unverified.
- Course registration and submission-format verification are handled by the user.
